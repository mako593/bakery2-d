
# こむぎ野区ベーカリー情報検索 MCPサーバー（非構造化版）

## 1. 概要

本サーバーは、卒業論文におけるAIレコメンド実験のために作成したMCP（Model Context Protocol）サーバーです。

架空の地域「こむぎ県こむぎ野区」に所在する30店舗のベーカリーについて、CSVファイルに登録された情報をAIに提供します。

登録されている店舗名、住所、開業日、商品、サービス等はすべて実験用の架空情報です。

## 2. 研究目的

本実験では、AIに提供する店舗情報の記述量と構造化の有無が、生成AIによる店舗推薦にどのような影響を与えるかを検証します。

MCP-A非構造化とMCP-B非構造化では、サーバーのプログラム、検索機能、CSVの列構成、店舗数、店舗属性の該当・非該当を統一します。

両条件で変更するのは、bakery.csvに記載された店舗説明文のみです。

また、構造化版のMCP-A・MCP-Bとの比較により、属性別に整理された情報と、一つの文章に統合された情報とで、AIの推薦結果にどのような違いが生じるかを検討します。

## 3. 登録店舗

登録店舗数：30店舗

対象地域：こむぎ県こむぎ野区（架空）

店舗名：ベーカリー1～ベーカリー30

すべて実験用に設定した架空店舗です。

## 4. CSVの項目

各店舗について以下の4項目を管理します。

1. 店舗名
2. 開業日
3. 住所
4. 店舗説明

店舗説明には、各店舗に設定された属性に関する説明文を一つに統合して記載します。

属性ごとの列や見出しは設けません。

## 5. 情報の取り扱い

店舗情報のデータソースはbakery.csvです。

CSVに記載された店舗説明文を、分割・要約・補完せずに提供します。

店舗説明に記載されていない商品やサービスについて、非対応であるとは判断しません。

サーバー側で11属性の判定や分類は行いません。

店舗の推薦順位や評価点はサーバー側では計算しません。

本サーバーは読み取り専用です。

## 6. MCPツール

### list_bakeries

登録されている全店舗の基本情報を取得します。

返却項目：
- 店舗名
- 開業日
- 住所

### get_bakery

指定した店舗名と完全一致する店舗の詳細情報を取得します。

引数：
- name：店舗名

返却項目：
- 店舗名
- 開業日
- 住所
- 店舗説明

### search_bakeries

指定したキーワードを含む店舗を検索します。

検索対象：
- 店舗名
- 住所
- 店舗説明

検索方法は部分文字列一致です。

店舗説明を属性ごとに分割せず、一つの文章として検索します。

引数：
- keyword：検索キーワード

### get_all_bakeries

全30店舗の詳細情報を取得します。

各店舗の説明文は、一つの文章として返します。

Python環境で以下を実行します。

    pip install -r requirements.txt

以下を実行します。

    python server.py

通信方式はstdioです。

MCPに対応するクライアントから接続して使用します。

## 11. MCP-A非構造化とMCP-B非構造化の共通条件

以下の条件を統一します。

- server.py
- requirements.txt
- README.md
- MCPツールの種類
- MCPツールの引数
- CSVの列構成
- 店舗数
- 店舗名
- 開業日
- 住所
- 11属性の該当・非該当
- 情報の取得・検索処理
- サーバーの通信方式

変更するのはbakery.csvの店舗説明文のみです。

## 12. 構造化版との比較

本研究では、以下の4条件を比較します。

条件1：MCP-A（構造化・簡潔な説明文）
条件2：MCP-B（構造化・詳細な説明文）
条件3：MCP-A非構造化（統合された簡潔な説明文）
条件4：MCP-B非構造化（統合された詳細な説明文）

構造化版では11属性を個別のCSV列として管理します。

非構造化版では11属性に関する説明文を、一つの店舗説明欄に統合します。

店舗名、開業日、住所はすべての条件で共通とします。

## 13. 実験上の注意

本サーバーが提供する情報は、すべて実験用の架空店舗データです。

登録されていない属性は、対応していないことを意味しません。

キーワード検索は文字列一致に基づくため、意味が近い表現でも文字列が一致しない場合は検索結果に含まれないことがあります。

AIによる店舗推薦結果は、使用モデル、質問文、ツールの呼び出し方などによって変化する可能性があります。

本サーバーは、実在する店舗の検索や実際の店舗情報の提供を目的としていません。
